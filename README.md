# Lunara

Lunara is a GPL-3.0 Android music player forked from Blazify, with the account and social surfaces removed.

## Included

- YouTube Music InnerTube catalogue, browse pages, artists, albums, playlists, and live home discovery
- Audio playback through Media3/ExoPlayer
- Queue, radio, autoplay, downloads, local music, favorites, history, and playlists
- Persistent mini-player and expanded player sheet
- Synced lyrics through Paxsenix, LRCLIB, KuGou, LyricsPlus, and related lyric modules
- Compose Material 3 UI with Lunara branding

## No-login policy

Lunara never restores or uses a Google/YouTube account cookie. The catalogue and discovery feed operate signed out.
